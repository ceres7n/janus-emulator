## Game data

ProjectPAULA ships game data that comes from the original Trickster Online game. The server cannot
run without it.

| Path | Contents | Origin |
|---|---|---|
| `db/*.yml` | Game tables: items, monsters, maps, NPCs and their dialogs, shops, skills, quests, drops and more | Converted from the original server data; a few tables from the game client's data. The header of each file names its source. |
| `db/stat_table.fnt2`, `db/exp_table.fnt2` | Stat and EXP tables | The original server's data files |
| `data/map/*.md3` | Map attribute files | The original game's map files |
| `tools/capture/sbox_cora.bin` | The packet cipher table | The game client |
